# First users playbook

Goal: enough reviews on common SKUs that scanning in a store feels useful.

1. You + 3–5 friends: each add 20 products (especially `never_again`).
2. Pick 2–3 supermarket chains you actually shop; focus barcodes from those shelves.
3. Share a Telegram/WhatsApp invite with the PWA link.
4. Track in PostHog (when key set): `search`, product page views, review created.
5. Success signal from the plan: user opens a product / never-again list ≥ 2 times in a month.

Do not pitch ads or price-compare until review density feels real.
